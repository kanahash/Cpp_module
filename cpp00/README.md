# C++ - Module 00: 要点まとめ

このモジュールは、C言語の「手続き型」からC++の「オブジェクト指向」へのパラダイムシフトを理解するための第一歩です。

---

## 1. 標準入出力（stdio.h から iostream へ）
C++では、関数呼び出しではなく **ストリーム（Stream）** という概念を用いて入出力を行います。

* **入出力オブジェクト**
    * `std::cout`: 標準出力ストリーム。
    * `std::cin`: 標準入力ストリーム。
    * `std::endl`: 改行を出力し、ストリームをフラッシュ（即時反映）する。
    * これらは関数ではなく、ライブラリで定義された **オブジェクト** です。

* **名前空間 (Namespace)**
    * すべての標準ライブラリは `std` 名前空間に属しています。
    * **禁止事項:** `using namespace std;`
        * 大規模開発において、標準ライブラリと自作コードの名前衝突を避けるため、42の課題および実務では原則として禁止されています。
        * 常に `std::` プレフィックスを付ける習慣をつけます。

---

## 2. クラスとカプセル化（Class & Encapsulation）
Cの `struct` から進化し、データと操作を一体化させたものが `class` です。

* **アクセス修飾子**
    | 修飾子 | 説明 | 用途 |
    | :--- | :--- | :--- |
    | `private` | クラス内部からのみアクセス可能 | **データ（属性）** を隠蔽し、不正な操作を防ぐ |
    | `public` | クラス外部からもアクセス可能 | **操作（メソッド）** を提供し、外部との窓口にする |

* **メンバ関数**
    * 属性（変数）とそれを扱う関数を1つの単位にまとめることで、**カプセル化**を実現します。これによりコードの再利用性と安全性が飛躍的に向上します。



---

## 3. オブジェクトのライフサイクル管理
オブジェクトの生成から破棄までを自動的に制御する仕組みです。

### ■ コンストラクタ (Constructor)
* オブジェクト生成時に自動で呼び出される特別な関数。
* 主にメンバ変数の初期化を担当します。

### ■ デストラクタ (Destructor)
* オブジェクトがスコープを抜ける際や破棄される際に自動で呼び出される関数。
* メモリの解放（Module 00では主に不要な後処理など）を担当します。

### ■ 初期化リスト (Member Initializer List)
* コンストラクタの本体（`{ }`）が実行される **前** にメンバ変数を初期化する構文。
* `const` 変数や参照型の初期化には必須であり、パフォーマンス面でも推奨されます。

```cpp
class Sample {
private:
    std::string _name;
public:
    // 初期化リストを使用したコンストラクタ
    Sample(std::string name) : _name(name) {
        std::cout << "Constructor called" << std::endl;
    }
    ~Sample() {
        std::cout << "Destructor called" << std::endl;
    }
};
