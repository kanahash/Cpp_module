### C++ Module05 ex00 : 要点まとめ
　→プログラムの実行中に発生する予期せぬエラーを処理する「例外処理(Exception)」
　独自の例外クラスを実装し、エラーを安全に投げる(throw)方法を学ぶ

#### 1．課題の目的
　→「役人(Bureaucrat)」クラスを作成し、その等級(Grade)が正しく管理されているか監視する
　不正な値が設定された場合に、C++の例外機構を使ってエラーを通知する仕組みを構築する

#### 2．等級(Grade)のルール
・有効範囲：1(最高)から150(最低)まで
・例外のトリガー
　→1より大きい値(0以下)を設定しようとすると、GradeTooHighException
　→150より小さい値(151以上)を設定しようとすると、GradeTooLowException

#### 3．独自の例外クラスの実装
　→例外は、std::exceptionを継承した内部クラスとして定義するのが一般的

・what()メソッドのオーバーライド
　→virtual const char* what() const throw();
　　エラーメッセージとして返す文字列を定義する
　　throw()は「この関数は例外を投げない」という指定(例外仕様)

#### 4．Try-Catch文によるエラー処理
　→例外が発生する可能性のある処理をtryブロックで囲み、発生したエラーをcatchブロックで捕まえる

### 5．実装のルール
・メンバ変数
　→ const std::string name： 名前は不変(定数)
　→ int grade：等級(1～150)

・メンバ関数
　→ getName(), getGrade() : ゲッター
　→ incrementGrade(), decrementGrade() : 等級を1つ上げ下げする
　※等級を挙げる=数値が減る(1に近づく)、下げる=数値が増える(150に近づく)

・出力ストリーム
　→operator<<をオーバーロードし、<name>, bureaucrat grade <grade>.と表示させる

### 6．テストすべき項目

| テストケース | 期待される挙動 |
| :--- | :--- |
| 正常系 | 等級 1 や 150 で作成でき、インクリメント等も範囲内なら動作するか。 |
| 高すぎる等級 | 0 を指定した際、GradeTooHighException が投げられるか。 |
| 低すぎる等級 | 151 を指定した際、GradeTooLowException が投げられるか。 |
| 境界値の変動 | 等級 1 をさらにインクリメントした際に例外が発生するか。 |

### 7．まとめ

| 項目 | 内容 |
| :--- | :--- |
| 主要技術 | 例外処理（try, catch, throw）、std::exception の継承 |
| 設計の鍵 | コンストラクタや更新関数内で即座に値をチェックし、不正なら即 throw すること |
| 安全性 | 不正な状態のオブジェクトが作成されるのを未然に防ぐ |

### 4．（コード例）
```cpp
try {
    Bureaucrat bob("Bob", 151); // ここで例外が投げられる
} catch (std::exception &e) {
    std::cerr << e.what() << std::endl; // エラーメッセージを表示
}
