# C++ Module 09 - ex02: PmergeMe 攻略メモ

## 📌 プログラムの全体像
本課題の目的は、比較回数を最小化する**「フォード・ジョンソン・アルゴリズム」**を理解し、**2つの異なるコンテナ**でその実行速度の差を計測することです。

### 1. フォード・ジョンソン・アルゴリズムとは？
別名：**マージ・インサーション・ソート（Merge-Insertion Sort）**
* **目的**: 「比較回数を極限まで少なくすること」

#### 💡 アルゴリズムの主なステップ
1.  **ペアを作る**: 数列を2個ずつのペアにし、ペア内での大小（大きい方）を特定する。
2.  **再帰的にソート**: 各ペアの大きい方の数値群（メインチェーン）を、本アルゴリズムで再帰的にソートする。
3.  **挿入（重要）**: 残った小さい方の数値群（ペンデント）を、ソート済みメインチェーンに**二分探索**を用いて挿入する。
4.  **ヤコブスタール数（Jacobsthal Number）の利用**: 挿入順を工夫し比較回数をさらに減らす（$1, 3, 5, 11, 21, \dots$ の順序で挿入範囲を決定）。



---

## 🛠 実装に必要な5つの技術

### ① 2つのコンテナの選択（禁止ルールに注意）
* **重要**: ex00 で `std::map`、ex01 で `std::stack`（内部で `std::deque`）を使用した場合、これらは**使用禁止**です。
* **推奨**: 一般的に **`std::vector`** と **`std::list`** の組み合わせが選ばれます。ランダムアクセスの可否による効率の差を比較するのが醍醐味です。

### ② 二分探索（`std::lower_bound`）
* 挿入ステップでは必ず二分探索を使用します。
* `std::vector` は高速ですが、`std::list` はイテレータの移動コスト（ポインタを辿る時間）がかかるため、その差が実行時間に顕著に現れます。

### ③ 時間計測（`clock()` または `gettimeofday()`）
* ソート開始直前と終了直後の差を**マイクロ秒（us）**などの精度で表示。
* **注意**: データのパース（読み込み）から管理にかかった時間もすべて計測に含める必要があります。

### ④ エラーハンドリング
* 負の数、および整数以外の入力（文字など）は `Error`。
* 重複値の扱いは任意（そのままソートするかエラーにするか方針を決める）。

### ⑤ 3000個以上の処理能力
* 大量データを扱うため、再帰の深さやメモリ管理を適切に行う必要があります。

| カテゴリ | テストケース例 | 期待される動作 |

## 💡 学習のアドバイス

### ヤコブスタール数を使わないとどうなるのか？
ヤコブスタール数を使わなくても「マージして挿入」すればソート自体は可能ですが、厳密にはフォード・ジョンソン・アルゴリズムとは呼べません。
評価者（Peer）から**「これはフォード・ジョンソンではない」**と指摘されるリスクを避けるため、挿入順序のロジックにはこの数列を組み込むのが無難です。
