## 🛠️ C++ - Module 02 ex02: 要点まとめ

> **核心テーマ**: ex01で作成した固定小数点数クラスに、「比較・算術・増減・静的メンバ関数」の演算子オーバーロードを実装し、数値型として完璧に機能させる。

---

### 1．課題の目的
* 2つの `Fixed` クラスを `int` や `float` と同じように、直感的な記号（`+`, `-`, `>`, `++` など）で操作できるようにする。

---

### 2．比較演算子のオーバーロード（6個）
2つの `Fixed` オブジェクトを比較し、`bool` 値を返す。
* **種類**: `>`, `<`, `>=`, `<=`, `==`, `!=`
* **ポイント**: 内部の `_value` 同士を比較するだけで実装可能。

---

### 3．算術演算子のオーバーロード（4個）
計算結果を新しい `Fixed` オブジェクトとして返す。
* **種類**: `+`, `-`, `*`, `/`
* **掛け算（*）の注意**: 
    * そのまま掛けると小数ビットが2倍（16bit分）になってしまうため、計算後に右シフト（`>> 8`）などで調整が必要。
* **割り算（/）の注意**: 
    * 精度を保つために、計算前に左シフト（`<< 8`）してから割るなどの工夫が必要。



---

### 4．増減演算子のオーバーロード（4個）
インクリメント（`++`）とデクリメント（`--`）の「前置」と「後置」を区別して実装する。

| 種類 | シグネチャの例 | 特徴 |
| :--- | :--- | :--- |
| **前置** (`++a`) | `Fixed &operator++()` | 値を増やした後、自身（`*this`）の参照を返す。 |
| **後置** (`a++`) | `Fixed operator++(int)` | コピーを取ってから値を増やし、増やす前のコピーを（値で）返す。 |

* **ポイント**: 後置の引数 `int` は、前置と区別するためだけのダミー引数である。



---

### 5．静的メンバ関数（min / max）
2つの参照を受け取り、小さい方（または大きい方）の参照を返す。
* `min(Fixed &a, Fixed &b)` / `max(Fixed &a, Fixed &b)`
* `min(const Fixed &a, const Fixed &b)` / `max(const Fixed &a, const Fixed &b)`
* **ポイント**: `static`（静的）であるため、インスタンス化せずに `Fixed::max(a, b)` と呼び出せる。

---

### 6．実装の注意点
* **戻り値の型**: 算術演算子は新しいオブジェクトを「値」で返し、比較演算子は `bool` を返す。
* **constの一貫性**: 比較演算子や、定数参照を受け取る `min/max` では、関数に `const` を付けて安全性を確保する。
* **内部値の操作**: 基本的に `getRawBits()` などを利用して内部の `_value` を操作する。

---

### 7．テストすべき項目

| テストケース | 期待される挙動 |
| :--- | :--- |
| **比較演算** | `a > b` などが正しい真偽値を返すか。 |
| **算術演算** | `a * b` や `a / b` が誤差の少ない正しい値を計算できるか。 |
| **前後置インクリメント** | `std::cout << a++ << ++a;` で値の変化のタイミングが正しいか。 |
| **min / max** | `Fixed::max(a, b)` が正しく大きい方を指し示すか。 |

---

### 8．まとめ

| 項目 | 内容 |
| :--- | :--- |
| **主要技術** | 演算子オーバーロード、static メンバ関数、前置・後置の区別 |
| **数学的調整** | 掛け算・割り算時のビット位置の調整（正規化） |
| **設計思想** | ユーザー定義型を組み込み型（int等）のように振る舞わせる |
