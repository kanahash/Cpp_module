## 🛠️ C++ - Module 02 ex01: 要点まとめ

> **核心テーマ**: ex00で作成した最小構成のクラスに、「整数・浮動小数点数との相互変換」と「出力ストリームへの対応」を実装し、実用的な固定小数点数クラスへ進化させる。

---

### 1．課題の目的
* 固定小数点数(Fixed-point)と、普段使っている整数(int)や浮動小数点数(float)を自由に行き来できるようにする。
* `std::cout << a;` のように直接オブジェクトを出力できるようにする。

---

### 2．コンストラクタの追加
ex00のデフォルトコンストラクタに加え、2つの新しいコンストラクタを実装する。

* **Intコンストラクタ**: 整数を受け取り、固定小数点形式に変換して保持する。
* **Floatコンストラクタ**: 浮動小数点数を受け取り、固定小数点形式に変換して保持する。

---

### 3．数値変換のロジック
小数部ビット数（`_bits = 8`）を使用する。

#### ➀ int ⇔ Fixed
* **int → Fixed**: 整数を $2^8$ (256) 倍する（ビットシフト `<< 8`）。
* **Fixed → int**: 保持している値を $2^8$ で割る（ビットシフト `>> 8`）。

#### ➁ Float ⇔ Fixed
* **Float → Fixed**: `float` 値に $2^8$ を掛け、その結果を最も近い整数に丸めて保持する。
* **Fixed → Float**: 保持している値を `(float)2^8` で割る。



---

### 4．メンバ関数の追加
* **`float toFloat(void) const`**: 固定小数点値を `float` に変換して返す。
* **`int toInt(void) const`**: 固定小数点値を `int` に変換して返す。

---

### 5．挿入演算子(<<)のオーバーロード
Fixedクラスのメンバ関数ではなく、**クラス外の関数**として実装する。これによって `std::cout` でFixedオブジェクトを直接表示できるようになる。



---

### 6．実装の注意点
* **丸め処理**: `float` から変換する際は、`roundf` 関数（`<cmath>`）を使用して精度を保つ必要がある。
* **ビットシフトの理解**: $2^n$ 掛けることは、左に $n$ ビットシフトすることと同じである。
* **constの付与**: 値を変更しないメンバ関数には適切に `const` を付け、OCCF（直交標準形）を維持する。

---

### 7．テストすべき項目

| テストケース | 期待される挙動 |
| :--- | :--- |
| **整数からの変換** | `Fixed(10)` が正しく `10` と表示されるか。 |
| **浮動小数点からの変換** | `Fixed(10.125f)` が精度を保って表示されるか。 |
| **出力ストリーム** | `std::cout << a;` で数値が正しく出力されるか。 |
| **OCCFの維持** | コピーコンストラクタや代入演算子が、変換後の値も正しく引き継ぐか。 |

---

### 8．まとめ

| 項目 | 内容 |
| :--- | :--- |
| **主要技術** | ビット演算（`<<`, `>>`）、`roundf`、演算子オーバーロード（`<<`） |
| **変換式** | $FixedValue = round(FloatValue \times 2^{bits})$ |
| **出力** | 浮動小数点形式で出力するのが一般的 |


### 5．挿入演算子(<<)のオーバーロード
Fixedクラスのメンバ関数ではなく、**クラス外の関数**として実装する。これによって `std::cout` でFixedオブジェクトを直接表示できるようになる。



```cpp
std::ostream &operator<<(std::ostream &o, Fixed const &i) {
    o << i.toFloat(); // floatに変換してストリームに流す
    return o;
}
