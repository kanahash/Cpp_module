## 🛠️ C++ - Module 02 ex00: 要点まとめ

> **核心テーマ**: C++におけるクラス設計の標準基準である「Orthodox Canonical Class Form (直交標準形)」を理解し、固定小数点クラス（Fixed）の最小構成を作成する。

---

### 1. 課題の目的
C++のクラスが「一人前のオブジェクト」として振る舞うために必要な、4つの特別なメンバ関数を正しく実装する方法を学ぶ（Orthodox Canonical Class Form）。

---

### 2. Orthodox Canonical Class Form (直交標準形) の4要素
C++98において、クラスを設計する際に必ずセットで実装すべき4つの関数。



| 関数名 | 役割 | 実装のポイント |
| :--- | :--- | :--- |
| **デフォルトコンストラクタ** | 引数なしでの初期化 | メンバ変数を初期値（ex00では0）で初期化する。 |
| **コピーコンストラクタ** | 既存のオブジェクトから複製 | 新しいオブジェクトを作る際、既存の値をコピーする。 |
| **コピー代入演算子** | 既存のオブジェクトへの代入 | `a = b` のように、既に存在するオブジェクトに値を上書きする。 |
| **デストラクタ** | オブジェクトの破棄 | メモリ解放などの後処理を行う（ex00ではメッセージ出力のみ）。 |

---

### 3. コピーコンストラクタ と コピー代入演算子
ここが混同しやすいため、違いを明確に理解する必要があります。

* **コピーコンストラクタ**: **「新しい」** オブジェクトを作る時に呼ばれる。
    * 例: `Fixed a; Fixed b(a);`
* **コピー代入演算子**: **「既にある」** オブジェクトに代入する時に呼ばれる。
    * 例: `Fixed a; Fixed b; b = a;`



---

### 4. 実装の具体的なルール
以下のルールに従ってメッセージを出力し、各関数が呼ばれる順番を確認する必要があります。

#### 🔹 メンバ変数
* **`int _value`**: 固定小数点の値を保持する（初期値 0）。
* **`static const int _bits`**: 小数部ビット数（常に 8）。

#### 🔹 メンバ関数
* **`getRawBits()`**: `_value` をそのまま返す。
* **`setRawBits(int const raw)`**: `_value` に値をセットする。

#### 🔹 メッセージ出力
各関数が呼ばれた際に、指定されたメッセージを `std::cout` で出力する。
* 例: `Default constructor called`, `Copy constructor called`, `Copy assignment operator called`, `Destructor called`, `getRawBits member function called`

### 5．コピー代入演算子の定型文
　→代入演算子を実装する際は、「自己代入のチェック」と「自分自身(*this)を返す」のが作法

### 6．聞かれるとしたら
#### ➀なぜコピー代入演算子でFixed＆を返すのか
　→連鎖代入(Chained Assignment)を可能にするため
　→C++の標準的な挙動では、a = b = c; という書き方が許容されている
　　これはa = (b = c); と右から順番に評価される

・(b = c) が実装されたとき、その戻り値がaへの代入に使われる
・もし戻り値がvoidだった場合、a = void となりコンパイルエラーとなる
・「参照(＆)」を返す理由
　→コピー(値渡し)を返すと、無駄な一時オブジェクトが生成され、パフォーマンスが低下する
　→自分自身(*this)の参照を返すことで、メモリ効率を最大化し、連続した操作をスムーズに行える



#### ➁なぜstatic const int _bits を使うのか
　→全インスタンスで共有される「クラス固有の定数」にするため

・static(静的)
　→・この変数は、オブジェクト(インスタンス)ごとではなく、クラスに1つだけ存在する
　→・固定小数点の「小数部が何ビットか」という情報は、全てのFixedオブジェクトで共通
　　オブジェクトごとにメモリを消費するのは無駄なので、staticにして共有する

・const(定数)
　→・少数ビット数は設計上、プログラム実行中に変わってはいけない値のため



### 7．必須のテスト項目

| テストケース | コード例（イメージ） | 期待される出力/挙動 |
| :--- | :--- | :--- |
| 1. デフォルト初期化 | Fixed a; | Default constructor called が表示され、値が 0 であること。 |
| 2. コピーコンストラクタ | Fixed b(a); | Copy constructor called が表示され、a と同じ値を持つこと。 |
| 3. コピー代入演算子 | Fixed c; c = b; | Copy assignment operator called が表示され、値がコピーされること。 |
| 4. getRawBitsの動作 | a.getRawBits(); | getRawBits member function called が表示されること。 |
| 5. 連鎖代入の確認 | a = b = c; | 代入演算子が2回呼ばれ、最終的にすべて同じ値になること。 |
| 6. デストラクタ | (スコープを抜ける) | Destructor called が作成した数だけ表示されること。 |

### 5．コピー代入演算子の定型文
　→代入演算子を実装する際は、「自己代入のチェック」と「自分自身(*this)を返す」のが作法

```cpp
Fixed &Fixed::operator=(const Fixed &src) {
    std::cout << "Copy assignment operator called" << std::endl;
    if (this != &src) { // 自己代入チェック
        this->_value = src.getRawBits();
    }
    return *this; // 自分自身を返す
}
