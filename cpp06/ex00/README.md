## 💎 C++ Module 06 ex00 : 要点まとめ

> **核心テーマ**: 文字列リテラルの解析と、`static_cast` を用いた安全な型変換の実装。

---

### 1．課題の目的
* 1つの文字列引数（例: `"42"`, `"42.0f"`, `'a'`) を受け取り、それを以下の4つの型に変換して表示する。
    * **char**
    * **int**
    * **float**
    * **double**
* C言語スタイルのキャストを避け、C++の明示的なキャスト（`static_cast`）を正しく使う。

---

### 2．型変換のプロセス
1. **型の特定 (Detection)**
    * 入力された文字列がどの型（char, int, float, double）として解釈されるべきかを判定する。
2. **変換 (Conversion)**
    * 文字列を実際のスカラー値（例: `double` 型）に変換する。
3. **キャスト (Casting)**
    * 取得した値を、`static_cast` を使って他の3つの型へ変換する。
4. **表示 (Display)**
    * 各型に応じた書式（精度や特殊なメッセージ）で出力する。



---

### 3．特殊な値（Pseudo literals）への対応
数学的に特殊なケースを正しく処理する必要がある。

* **float**: `nanf`, `+inff`, `-inff`
* **double**: `nan`, `+inf`, `-inf`
* **出力ルール**
    * `int` や `char` に変換できない場合は **"impossible"** と表示する。

---

### 4．表示の制御
* **Non displayable**
    * `char` に変換はできるが、表示可能な文字（ASCII 32-126）ではない場合に表示する。
* **精度の維持**
    * 浮動小数点数（float/double）の出力時、小数点以下が 0 の場合は `.0` を付けて表示する（例: `42.0f`）。

---

### 5．実装のルール
* **クラス設計**
    * `ScalarConverter` クラスを作成する。
* **静的メソッド**
    * インスタンス化して使う必要はないため、メソッドは `static` にする（コンストラクタなどは `private` に置く）。
* **使用禁止**
    * Cスタイルのキャスト `(int)x` は厳禁。

---

### 6．テストすべき項目

| 入力例 | 期待される挙動 |
| :--- | :--- |
| `'a'` | char: 'a', int: 97, float: 97.0f, double: 97.0 |
| `"0"` | char: Non displayable, int: 0, float: 0.0f, double: 0.0 |
| `"42.0f"` | 42として各型に正しく変換されるか。 |
| `"nan"` | char: impossible, int: impossible, float: nanf, double: nan |
| `"42.42"` | doubleの精度を保ちつつ、int/charでは適切に切り捨てられるか。 |

---

### 7．まとめ

| 項目 | 内容 |
| :--- | :--- |
| **主要技術** | `static_cast`, 文字列解析（`strtod` 等）, `std::iomanip` |
| **設計の鍵** | 文字列を一度最大の精度（`double` 等）で受け取ってから、各型へ安全にキャストする |
| **エラー処理** | 変換不能な値やオーバーフローに対する適切なメッセージ出力 |
